Lore and definitions

String Alphabet
A simple written code that represents letters with assigned numeric values.
Token
A single value in a sequence. Tokens are separated by punctuation or spacing.
Delimiter
A slash, comma, or space used to separate parts of a sequence.
Archive notation
A format used in older notes where numbers and separators are preserved as written.

The system is maintained as a small reference cipher. Values are fixed in this version; unknown sequences are left unchanged so they can be reviewed manually.
